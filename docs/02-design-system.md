# Afroz Digital Seva — Design System

## Primary Colors

| Name | Color | Usage |
|---|---|---|
| Brand Navy | `#021226` | Navbar, footer and dark sections |
| Brand Blue | `#0878F9` | Buttons, links and highlights |
| Brand Green | `#00A86B` | Success and WhatsApp actions |
| Brand Orange | `#FF7A1A` | Important highlights |
| Surface | `#F7FAFE` | Main page background |
| Text Dark | `#07172F` | Headings and body text |
| Text Muted | `#65748B` | Secondary text |

## Typography

- Primary font: Inter
- Display headings: Poppins
- Handwritten highlights: Caveat

## Layout Width

- Maximum content width: 1280px
- Mobile horizontal padding: 16px
- Tablet horizontal padding: 24px
- Desktop horizontal padding: 32px

## Responsive Breakpoints

- Mobile: 320px–639px
- Tablet: 640px–1023px
- Laptop: 1024px–1279px
- Desktop: 1280px and above

## Design Principles

- Mobile-first responsive design
- Clear government-service navigation
- High text readability
- Consistent spacing and colors
- Minimal, useful animation
- Fast-loading interface
